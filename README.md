# Research project boilerplate

A fork-ready skeleton for an empirical research project: a LaTeX manuscript
(with an optional online supplement), the figures and tables it consumes, the
analysis code that generates them, and a one-command arXiv packager.

The manuscript is the [academic paper template](paper/README.md) — see that
README for the preamble's features (fonts, citations, cross-references, theorem
and supplement machinery) and the customization checklist.

## Layout

| Path | Contents |
|------|----------|
| `paper/` | The manuscript. `ms.tex` is the paper; `prompt.md` helps drop a draft into the template; `README.md` documents the template. |
| `references.bib` | Shared bibliography (biblatex), used by `paper/` (and `slides/`, etc.). |
| `figures/` | Figures the paper `\includegraphics` / `\input`s. Generated by `programs/`. |
| `tables/` | Tables the paper `\input`s. Generated by `programs/`. |
| `data/` | Input datasets. |
| `programs/` | Analysis code (Stata / R / Python / …) that reads `data/` and writes `figures/` + `tables/`. |
| `slides/` | Talk slides. |
| `package_paper.sh` | Builds the paper and bundles a self-contained arXiv upload. |

`paper/ms.tex` reaches the shared assets through relative paths
(`../figures/`, `../tables/`, `../references.bib`), so compile it from inside
`paper/`.

## Compiling the paper

```sh
cd paper
latexmk -pdf ms
```

The bibliography uses **biblatex + biber**; `latexmk` runs the biber pass for
you. Tested with TeX Live 2025 / MiKTeX. The paper ships with the free
**Cochineal** font stack, so it builds out of the box (see
[paper/README.md → Fonts](paper/README.md#fonts)).

## Packaging for arXiv

```sh
./package_paper.sh
```

This builds `paper/ms.tex`, drops a dated PDF (`paper_YYYY-MM-DD.pdf`) at the
project root, and assembles `paper_package/` + `paper_paper.zip` containing
`ms.tex`, `ms.bbl`, and everything in `figures/` and `tables/`. Upload the zip
to arXiv. Set `PAPERNAME` at the top of the script to rename the outputs.

The script won't overwrite existing outputs — delete `paper_package/`, the
`.zip`, and/or the dated `.pdf` before re-running.

### Fonts on arXiv

arXiv builds the free Cochineal stack directly, so by default the packager
leaves the fonts alone. If you switch `paper/ms.tex` to the commercial **Minion
Pro** stack for a camera-ready build (see
[paper/README.md → Fonts](paper/README.md#fonts)), the packager notices the
active `%%not-arxiv-font%%` line and swaps *the packaged copy* back to the free
`%%arxiv-font%%` stack automatically. Your source file is never touched.

## Requirements

A TeX distribution (TeX Live 2025 / MiKTeX) with `latexmk` + `biber`, plus
`zip` and a POSIX shell (Git Bash on Windows) to run `package_paper.sh`.
